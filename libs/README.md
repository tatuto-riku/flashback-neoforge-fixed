# Compile-only dependencies

Place the following third-party jars in this directory before building:

- `Flashback-0.39.7-for-MC1.21.1_mapped_moj_1.21.1.jar`
- `sable-neoforge-1.21.1-2.0.5.jar`
- `sable-companion-common-1.21.1-1.6.0.jar`

The jars are excluded from Git and are never bundled into this mod.
